# > list LlamaIndex books, from introduction level to advanced level

Here is a curated progression of books covering LlamaIndex and Retrieval-Augmented Generation (RAG), structured from introductory concepts to production-grade engineering.
------------------------------
## Phase 1: Introduction & Foundations (No prior LLM experience)
These books introduce LlamaIndex as part of a broader introduction to generative AI development, focusing on basic script writing and standard document parsing. [1] 

* **Developing Apps with GPT-4 and ChatGPT**
* Authors: Olivier Caelen, Marie-Alice Blete
   * Focus: An excellent starting point for Python developers transitioning to LLMs. It provides high-level foundational contexts for prompt engineering and APIs. It features introductory chapters on how frameworks like LangChain and LlamaIndex help bridge local data gaps. [2, 3] 
* **Hugging Face in Action: Build Intelligent Applications with Transformers, Agents, and RAG**
* Author: Wei-Meng Lee
   * Focus: Perfect for beginners looking to blend open-source software with LlamaIndex. It teaches tokenization, working with open datasets, and building simple local data-query apps using GPT4All or basic LlamaIndex ingestion pipelines. [4] 

------------------------------
## Phase 2: Intermediate Level (Core LlamaIndex Architecture)
These books are dedicated entirely to the LlamaIndex framework. They explore data parsing strategies, vector store connections, and fundamental RAG indexing patterns. [5, 6, 7] 

* **Building Data-Driven Applications with LlamaIndex**
* Publisher: Packt / [O'Reilly](https://www.oreilly.com/library/view/building-data-driven-applications/9781835089507/)
   * Focus: The definitive complete guide to the LlamaIndex ecosystem. It features a practical progressive-complexity build called "MOPeT" (My Own Personal Teacher). It systematically breaks down the core pipeline abstractions: Documents, Nodes, VectorStoreIndex, and standard metadata routers. [1, 8, 9, 10, 11] 
* **Mastering LlamaIndex: Simplifying Data Access for Large Language Models**
* Author: Robert Johnson
   * Focus: An authoritative overview designed for data scientists and technical professionals. It bridges the gap between raw data files and semantic embeddings, exploring real-world configurations across finance and healthcare industries. [12] 
* **Data Analysis with LLMs**
* Author: Immanuel Trummer (Cornell University Professor)
   * Focus: Tailored for data analysts wanting to write natural language query interfaces over multi-modal datalakes. It covers using LlamaIndex structures to index, cluster, and execute calculations across non-textual or tabular data sources. [13] 

------------------------------
## Phase 3: Advanced Level (Agents & Production Architectures)
These books assume a strong grasp of Python and basic RAG pipelines, shifting focus entirely toward multi-agent coordination, orchestration, and enterprise scale.

* **Agentic Workflow Construction**
* Author: Theodore Langmere
   * Focus: Written specifically for technical architects and engineers. It examines the intersection of role-based agent frameworks (like CrewAI) paired directly with LlamaIndex for advanced data-aware indexing, custom tools, and multi-step complex process tracking. [14] 
* **Building AI Agents from Scratch: A Developer’s Roadmap**
* Author: Jevon Michael
   * Focus: Moves far beyond conversational chatbots. This book covers complex cognitive patterns: memory management, prompt optimization loops, observability, and debugging multi-agent deployments built on LlamaIndex and AutoGen. [15, 16] 
* **Agentic AI for Cybersecurity: Building Autonomous Defenders and Adversaries**
* Author: Omar Santos
   * Focus: A hyper-specialized production manual focusing heavily on security-first frameworks. It outlines how to deploy LlamaIndex engines safely alongside Model Context Protocols (MCP) and agentic loops for real-time security auditing and defense. [17] 

------------------------------
## Alternative Resource Note
Because the LlamaIndex API updates frequently, physical books can sometimes lag behind the latest library syntax changes. To supplement these readings, review the Official LlamaIndex Documentation or interactive modules on DeepLearning.AI, which frequently hosts video-based code walkthroughs co-developed by the LlamaIndex core team. [18, 19, 20]
