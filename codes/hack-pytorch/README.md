# Hack PyTorch

Setup
```shell
$ uv init hack-pytorch

$ uv add torch torchvision torchaudio
$ uv add accelerate
$ uv add torchinfo


# KaggleHub
$ uv add kagglehub

# Hugging Face
$ uv add transformers huggingface_hub
$ uv add timm

$ uv add numpy matplotlib pandas
$ uv add notebook
$ uv add ipywidgets
$ uv add python-dotenv
```
