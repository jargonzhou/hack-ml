# > list MLOps books, from introduction, intermediate to advanced.

Here is a curated list of essential MLOps books structured progressively from introductory concepts to advanced enterprise infrastructure.
## Introduction (Foundations & High-Level Strategy)
These books bridge the gap between experimental code and production systems, focusing on strategy, workflows, and culture. [1, 2, 3] 

* [**Introducing MLOps**: How to Scale Machine Learning in the Enterprise](https://www.goodreads.com/shelf/show/mlops) by Mark Treveil and the Dataiku Team. Covers the "why" and basic lifecycle of MLOps for beginners and managers.
* **Building Machine Learning Powered Applications**: Going from Idea to Product by Emmanuel Ameisen. Focuses on taking a project from an idea to a deployed, iterative product.
* **Machine Learning Engineering** by Andriy Burkov. A concise guide covering data collection, engineering, training, and deployment. [4, 5, 6, 7, 8, 9, 10] 

## Intermediate (Core Architecture & Pipeline Implementation)
These titles focus on writing modular code, building automated pipelines, and managing system design.

* **Designing Machine Learning Systems**: An Iterative Process for Production-Ready Applications by Chip Huyen. Explores system design, feature stores, and data drift.
* **Practical MLOps**: Operationalizing Machine Learning Models by Noah Gift and Alfredo Deza. Applies DevOps principles like CI/CD to machine learning using cloud tools.
* **Machine Learning Engineering in Action** by Ben Wilson. Addresses real-world challenges in testing and deploying models. [4, 5, 6, 7, 10, 11, 12] 

## Advanced (Enterprise Scale, Infrastructure & LLMOps)
Focused on massive scalability, reliability, and modern LLM infrastructure. [5, 13] 

* [**MLOps Engineering at Scale**](https://www.oreilly.com/library/view/mlops-engineering-at/9781617297762/) by Carl Osipov. Covers cloud-native systems, containerization, and distributed infrastructure.
* Reliable Machine Learning: Applying SRE Principles to ML in Production by Cathy Chen, Niall Richard Murphy, et al. Applies SRE concepts to ML, focusing on incident response and data pipeline reliability.
* [**Effective Data Science Infrastructure**](https://www.good, reads.com) by Ville Tuulos. Details designing data platforms, covering compute layers and tool-agnostic patterns.
* [**MLOps with Databricks**](https://www.oreilly.com/library/view/mlops-with-databricks/9798341608245/) by O'Reilly. Covers advanced topics including Lakehouse monitoring and LLMOps. [4, 5, 7, 8, 14, 15, 16]
